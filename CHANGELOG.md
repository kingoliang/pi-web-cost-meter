# Changelog

## 0.1.0

- Cost page under a project and a machine-wide Cost page: calls, cost, token
  buckets, per model, per project, per day, over a chosen period.
- One-line cost note beside each session in the navigator.
- Price table, currency, USD→CNY rate and scan window in Settings.
- Prices every call whose provider recorded no cost; a recorded cost wins.
- Reads Pi session transcripts only; no network, no runtime dependencies.
